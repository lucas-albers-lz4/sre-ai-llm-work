# Submit a Source to SRE AI LLM Work

Found something useful about AI/LLMs in SRE, on-call, observability, runbooks,
or LLM production reliability? We want it.

## What We're Looking For

- Practitioner posts, postmortems, and failure reports
- Runbooks / AGENTS.md / ops agent configs from real repos
- Observability + AI writeups with concrete evidence
- LLM ops reliability (SLOs, evals, cost, incident stories)

## What We Reject

- Vendor marketing without practitioner evidence
- Pure AI coding-agent content with no ops/reliability angle
- Duplicates of existing source notes
- Pre-2025-12-01 material (unless still uniquely load-bearing)

## How to Submit

Use the issue templates under `.github/ISSUE_TEMPLATE/`:

- Source submission
- Seed site
- Practitioner repo
- Failure report

The Prospector triages; the Miner extracts; the Assayer reviews.
